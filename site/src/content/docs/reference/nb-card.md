## Properties and attributes

| Name       | Type                    | Default     | Notes                      |
| ---------- | ----------------------- | ----------- | -------------------------- |
| `variant`  | `'primary' \| 'accent'` | `'primary'` | Reflected to the attribute |

```js
const button = document.querySelector('nb-card')
button.variant = 'accent'
```
