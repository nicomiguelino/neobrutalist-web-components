## Why these components

<CardGrid>
	<Card title="Works anywhere" icon="rocket">
		Built with Lit as standard custom elements. Use them in a bundler, a module script, or a classic `<script>` tag.
	</Card>
	<Card title="Typed" icon="pencil">
		Types ship with the package, and elements are registered in `HTMLElementTagNameMap`.
	</Card>
	<Card title="Themeable" icon="setting">
		Colors, border width, and shadow offset are CSS custom properties that pass through shadow DOM.
	</Card>
	<Card title="Work in progress" icon="information">
		The library is published, but it's still a work in progress. Components land one at a time. See the [`nb-button` reference](reference/nb-button/).
	</Card>
</CardGrid>
